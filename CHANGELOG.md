# Changelog

## 2026-08-12

- Исправлен баг «Ничья по весу» (см. `TASKS.md`): у `grizzly-bear` и `zebra`
  в `src/data/level1.ts` одинаковый `value: 350` кг, из-за чего
  `generateNewPair` в `src/components/GameLevel.tsx` всегда засчитывал
  верным `itemA`, а правильный ответ игрока по `itemB` штрафовался на −2.
  Теперь при совпадении значений в случайной паре функция ищет в
  перетасованном списке следующего кандидата на `itemB` с другим значением,
  прежде чем определять правильный ответ — исправление общее для всех
  уровней. Задача про фото 11 животных (часть 2 из 2) вновь пропущена: она
  требует либо доступа в интернет, либо платной AI-генерации с согласия
  пользователя — ни то, ни другое недоступно в автоматическом прогоне.

## 2026-08-10
