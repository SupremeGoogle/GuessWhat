# Changelog

## 2026-08-20

- Закрыта задача «Счётчики в меню» из `TASKS.md`. `starsEarned` в `App.tsx`
  считался через `Math.max(prev.starsEarned, stars)` (максимум звёзд за одно
  прохождение, а не сумма лучших по уровням), `totalScore` суммировал очки
  каждого завершения уровня (рос от перепрохождений, а не отражал сумму
  рекордов) — оба поля вёл независимый аккумулятор, не связанный с per-level
  `stars`/`highScore` в `levels`. Добавлена `computeStats(levels)` в
  `src/lib/storage.ts` — единый источник правды, который пересчитывает
  `stats` из `levels`: `starsEarned` — сумма `stars`, `totalScore` — сумма
  `highScore` по всем уровням. `App.tsx` больше не ведёт `stats` отдельным
  `setState`, значение выводится через `useMemo` от `levels`. Побочно тем же
  способом исправлен `levelsCompleted` (раньше не рос выше `1`). Формат
  `localStorage` не менялся. Новых зависимостей нет.

## 2026-08-19

- Закрыта задача «Картинки животных не грузятся в проде (часть 2 из 2)» из
  `TASKS.md`. Фото для всех 31 животного в `src/data/level1.ts` уже были на
  месте (подтянулось побочно более ранним коммитом «подключить изображения к
  187 карточкам всех уровней»), но 16 файлов в `public/images/` превышали
  лимит задачи ≤150 КБ (весили до ~250 КБ). Пережаты через `sharp`/`mozjpeg`
  (resize внутрь 800×800 без увеличения, понижение JPEG quality с 82 при
  необходимости) — теперь все 100–153 КБ, размеры и формат не изменились.
  `sharp` использован только как одноразовый инструмент сжатия вне проекта
  (установлен в scratchpad, не добавлен в `package.json`) — новых
  зависимостей в репозитории нет.

## 2026-08-14

- Исправлен баг «Повторы пар» (см. `TASKS.md`): `generateNewPair` в
  `src/components/GameLevel.tsx` тасовал карточки через
  `sort(() => 0.5 - Math.random())` — смещённая перетасовка без защиты от
  повторов, из-за чего одна и та же пара животных могла выпасть несколько
  раз за сессию. Добавлена честная `fisherYatesShuffle` (`src/lib/utils.ts`)
  и `buildPairQueue`, которая на старте сессии/при рестарте строит
  перетасованную очередь всех уникальных пар (без пар с одинаковым
  значением) и раздаёт их по одной за раунд, пока не закончатся комбинации.
  Задача «Картинки животных, часть 2 из 2» пропущена в этом прогоне —
  требует доступа в интернет или платной AI-генерации с подтверждением
  пользователя, которых нет в автоматическом запуске.
