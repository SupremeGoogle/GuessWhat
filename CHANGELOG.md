# Changelog

## 2026-09-02

- Закрыта задача «Тактильная отдача (Vibration API) на верный/неверный
  ответ» из `TASKS.md`. `audio.playWrong()` в `src/utils/audio.ts` уже
  вызывал `navigator.vibrate([100, 50, 100])` (паттерн из двух импульсов),
  а `audio.playCorrect()` — нет. Добавлен приватный хелпер
  `SoundManager.vibrate(pattern)` с проверкой `'vibrate' in navigator`
  (не падает в браузерах без поддержки, например iOS Safari);
  `playCorrect()` теперь даёт один короткий импульс (`vibrate(40)`),
  `playWrong()` переведён на тот же хелпер с прежним паттерном. Вибрация
  отключается вместе со звуком через общий флаг `isMuted`. Новых
  зависимостей нет.
